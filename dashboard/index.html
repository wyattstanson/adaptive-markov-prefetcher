Four stages, one pass per access

Each stage sits behind its own interface, so any of them can be inspected or swapped without touching the others.

Why two pages of context

A first-order model sees only the last page. When two paths share a middle page, it can predict only one of their successors.

Read the phase, then pick the rule

Prefetching during a random phase evicts useful pages for guesses that will not hit, so the engine turns it off there.
